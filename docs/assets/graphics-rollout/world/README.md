# World materials and machinery

This kit extends the approved quartermaster's worn industrial material language to existing first-person environment consumers. It contains original Blender geometry, procedural material nodes, orthographic cameras and three area lights. It imports no external models or image textures and requires no add-ons, paid service or browser dependency. The parent-owned Ashfall panorama and terrain generation are separate from this kit.

The machine-readable subject and path authority is `game/scripts/world-assets/catalog.json`. It names exactly 32 outputs: four utility facade replacements, two construction floor replacements, five utility/construction prop replacements, 17 room/station/ruin materials and four additional machinery/dressing props. Existing mine facade, M3 hub art and quartermaster assets are untouched.

The five utility rooms have distinct functional motifs: solar power ducts and regulator heat sinks; farm insulated glazing and irrigation drainage; purifier pressure mains and a central floor drain; habitat insulation, narrow windows and rubber flooring; mine exposed rock, bracing and embedded haulage rails. Station materials use armored plate, vents and small cold emergency lights. Ruins use fractured mineral surfaces, exposed steel reinforcement and severed cables. Cyan and amber occur only on small lamps or displays.

## Rebuild

From the repository root, using Blender 4.4.3 and Python with Pillow:

```sh
/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python game/scripts/world-assets/render_world.py -- --sample
python3 game/scripts/world-assets/verify_world.py --sample

/Applications/Blender.app/Contents/MacOS/Blender --background --factory-startup --python game/scripts/world-assets/render_world.py
python3 game/scripts/world-assets/verify_world.py
/Applications/Blender.app/Contents/MacOS/Blender --background docs/assets/graphics-rollout/world/world-kit.blend --python game/scripts/world-assets/inspect_source.py
```

`--only <asset-id> ...` restricts a render to catalog entries. `--source-only` rebuilds editable geometry without rendering. A restricted full invocation writes a restricted `world-kit.blend`; run the complete invocation to restore the full kit. Samples use `world-kit-samples.blend` and do not overwrite runtime PNGs.

Tile sources are 512×512 opaque PNGs. Their modular geometry repeats at the boundaries. Runtime tiles retain the raw rendered pixels; baked-light/procedural-noise differences across opposite edges are reported in seam metrics, not hidden by raster editing. Props render at 1024×1024 RGBA with unclipped silhouettes; the verification script crops transparent margins, preserves the subject's proportions, and places it on a 512×512 transparent runtime canvas with bottom contact. The source PNGs remain unchanged. Sampling and square prop-plane contracts are controlled by the runtime renderer.

`world-kit.blend` retains one editable collection per asset. Only the last rendered collection is visible when opened. Toggle collection visibility to inspect another subject, or use the script for its exact camera. Materials remain editable node graphs; dimensions and construction are parameterized in the Python generator. The file uses compressed Blender storage and contains no external references requiring packing.

## Evidence

`manifest.json` records final runtime/source dimensions, alpha bounds, bytes and SHA-256 hashes, plus tile seam metrics. `source-build.json` records Blender version and per-collection object counts. `source-verification.json` independently checks the saved Blender file's 32 asset collections, mesh/vertex census, render metadata and lack of external image dependencies. Material and prop contact sheets, 128-pixel dark/bright prop comparisons and 2×2 tiling previews are generated by `verify_world.py`. The verifier's `--only <asset-id> ...` mode stages a completed subset and writes `partial-verification.json` without replacing the complete manifest.

The verifier checks exact dimensions, full opacity of textures, transparent prop backgrounds, source silhouette margins and bottom contact. Its art checks do not replace a production gameplay review. Runtime integration, collision-safe placements, performance, renderer changes and the final screenshot evidence belong to the parent lane.
